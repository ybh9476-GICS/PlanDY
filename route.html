유풍 창고 관리 시스템(WMS) 개요

카드로 정리된 WMS 기획 제안 및 핵심 용어

유풍 창고 관리 시스템(WMS) 개요

디지털 트윈 기반 창고관리시스템(WMS) 기획 제안 및 핵심 운용 프로세스

시스템 기획 개요 및 프로세스 흐름

본 유풍 창고 관리 시스템(WMS, Warehouse Management System) 프로젝트는 3D 디지털 트윈 환경을 구축하여 공장 → 건물 → 층 → 범위 → 구역 → 랙 → 단에 이르는 로케이션 계층 구조를 직관적으로 조망하고, 최적 자재 배치 및 층간 승강기(E/V) 연계 경로 검색을 제공합니다.

graph TD A[1. 출발지 & 도착지 검색 조건 입력] --> B[2. 자재/완제품 분류 탭 및 품목 슬롯 선택] B --> C[3. 선택 층 재고 및 여유공간 인디케이터 확인] C --> D[4. 최적 랙 Location ID 도출: B2C / G2D] D --> E[5. 1F 출입구 ➔ E/V ➔ 2F 3D 이동 경로 렌더링] E --> F[6. 3D 빌보드 기점 및 작업자 가이드 제공]

1F 선택층 현황 & 자재 인디케이터

국가, 공장, 건물, 층 드롭다운 선택 시 상단에 원단, 테이프, 밴드, 단추, 포장재의 재고/여유공간이 인디케이터 바 형태로 즉시 조망됩니다.

3D 층간 E/V 연계 최적 경로 가이드

1F 출입구부터 1F E/V, 2F E/V를 거쳐 2F 부자재 창고의 G2D 랙까지 이어지는 수평/수직 이동 동선을 3D 그린 라인 및 빌보드로 안내합니다.

WMS 핵심 용어 및 구조 명세

용어 (Term) 기능 명칭 핵심 내용 및 편집 기능 명세
층 (Floor) 층 편집 층별 면적 정보 입력 시 해당 건물에 자동으로 층 생성 및 층별 창고 현황을 조망할 수 있습니다.
범위 (Zone) 범위 편집 자재 및 완제품 별로 구분되는 영역. 저작도구를 이용해 층 내 범위를 생성하고 정보 확인이 가능합니다.
구역 (Area) 구역 편집 작업자 동선으로 구분되는 랙(Rack)의 집합. 행/열 개수 및 정렬방식, 랙 타입을 지정하여 자동 교차점 배치합니다.
단 (Level) 단 (ID) 랙의 층 단위. 랙의 단별로 자동 Location ID가 부여되며 자재 및 완제품 등록/재고 및 여유공간 현황을 파악합니다.

  • Editor 메뉴 관리: 메뉴를 추가·수정·삭제·정렬합니다.

      • 게시본 불러오기: GitHub에 게시된 기준 JSON 내용을 현재 브라우저에 불러옵니다.
      • 내보낸 JSON 파일을 Git에 커밋·푸시하면 GitHub에도 같은 콘텐츠를 게시할 수 있습니다.

  • 도움말: 주요 기능과 사용 방법을 확인합니다.
  • 권한 설정: 현재 권한을 변경하거나 로그아웃합니다.

선택한 메뉴의 카드 목록을 표시합니다. 카드는 1열·2열·3열 구조로 배치할 수 있습니다.

카드는 헤더, 헤더 설명, 이미지, 텍스트 또는 테이블 본문으로 구성됩니다.

카드 목록 아래의 카드 추가 버튼에서 1열·2열·3열 유형을 선택해 생성합니다.

  • 카드는 좌 → 우, 상 → 하 순으로 배치됩니다.
  • 카드의 ↑, ↓ 버튼으로 읽기 순서를 바꿉니다.
  • 카드 순서를 지정해 AI에게 카드 내용 생성을 요청할 수 있습니다.
    예) 2번 카드에 기획 내용을 요약해줘.
  • 2열·3열 카드 행에서 카드 사이의 경계선을 좌우로 드래그해 각 카드의 폭을 조절합니다.
  • Viewer는 카드 폭을 조절할 수 없습니다.
  • 카드의 Edit 버튼을 눌러 제목, 설명, 이미지, 본문을 수정합니다.
  • + 이미지 추가에서 파일 업로드, 드래그앤드롭, 붙여넣기로 이미지를 등록합니다.
  • 이미지 위에 마우스를 올려 원본보기를 선택할 수 있습니다.
  • + PDF 추가에서 PDF 파일을 선택하거나 편집 영역에 끌어 놓습니다.
  • 카드에는 PDF의 첫 페이지가 미리보기로 표시됩니다.
  • PDF 미리보기에 마우스를 올려 원본보기를 누르면 전체 페이지를 스크롤로 확인할 수 있습니다.
  • + Google Drive 문서 추가에서 Google Docs, Sheets, Slides의 공유 링크를 붙여넣습니다.
  • 카드에는 문서 썸네일이 표시되며, 불러오지 못하면 문서 유형 안내가 대신 표시됩니다.
  • 썸네일에 마우스를 올려 원본보기를 누르면 뷰어에서 확인할 수 있고, 필요하면 새 탭에서 열기를 선택합니다.
  • + 본문 추가를 누른 뒤 텍스트를 선택해 본문 블록을 만듭니다.
  • Enter: 다음 줄을 작성합니다.
  • 1. 내용 뒤 Enter: 다음 번호를 자동으로 만듭니다.
  • •, ◦, -: 글머리 기호를 작성합니다. /를 입력하면 목록 유형을 선택할 수 있습니다.
  • Tab: 들여쓰기 / Shift + Tab: 내어쓰기
  • 최상위 목록에서 Shift + Tab: 번호 또는 기호를 제거하고 일반 텍스트로 바꿉니다.
  • 텍스트 선택: Bold, Regular, 글자색을 적용합니다.
  • + 본문 추가를 누른 뒤 테이블을 선택해 테이블 블록을 만듭니다.
  • 테이블 셀에서 Enter로 줄을 바꿀 수 있으며, 긴 글은 자동 줄바꿈되고 행 높이도 함께 늘어납니다.
  • 열 경계를 드래그해 열 너비를 조절합니다.
  • 수정이 끝나면 등록을 눌러 저장합니다.
  • 삭제를 누르면 카드를 삭제하며, 작성된 내용이 있으면 확인 창이 표시됩니다.
  • AI 다이어그램처럼 수정할 수 없는 카드는 Edit 버튼이 비활성화될 수 있습니다.
