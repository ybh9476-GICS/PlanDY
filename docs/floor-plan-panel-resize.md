# 평면도 에디터 패널 폭 조절 (2026-09-18)

## 적용 내용

- 좌측 배치 도구 패널과 도면, 도면과 우측 속성 패널 사이의 경계를 드래그해 폭을 조절한다. 패널의 기존 항목, 순서, 값, 기능은 유지한다.
- 패널 폭에 따라 도구 버튼과 속성 입력란이 자동으로 여러 열 또는 한 열로 정렬된다. 버튼과 설명도 가능한 폭에 맞춰 줄바꿈한다.
- 좌측 폭은 100–420px, 우측 폭은 200–600px 범위이며 도면 작업 영역을 최소 220px 확보한다. 창을 줄이면 가능한 범위로 패널 폭을 조정한다.
- 조절 경계를 더블클릭하면 해당 패널의 기본 폭으로 복원한다. 경계에 키보드 포커스를 둔 상태에서 좌우 방향키로 10px, Shift와 함께 30px 조절하며 Home/End는 최소/최대 폭으로 이동한다.
- 브라우저 폭 900px 이하에서는 기존 작은 화면 배치를 유지하며 조절 경계는 숨긴다. 패널 폭은 실행 중 화면 상태로만 유지하며 새로고침하면 기본 폭이다. 도면 저장 키와 저장 형식은 변경하지 않는다.

## 수정 파일

- `js/floor-plan-editor.js`: 경계 UI, 포인터 드래그·키보드 조절, 폭 제한, 창 크기 대응 및 이벤트 정리.
- `css/floor-plan-editor.css`: 조절 가능한 열 배치, 조절 경계 스타일, 패널 내부 자동 열 배치와 줄바꿈.
- `index.html`: 에디터 JS v17, CSS v10 캐시 버전. `npm.cmd run sync:pages`로 호환 진입 페이지 12개 동기화.
- `tests/floor-plan-panel-browser.cjs`: Viewer/Editor 패널 조절과 기존 편집 동작 검증.
- 이 문서와 `docs/floor-plan-editor.md`: 적용 및 검증 기록.

## 검증 결과

- 변경 전 `npm.cmd test` 전체 통과. 독립 Edge 브라우저에서 조절 경계가 없고 좌우 패널 폭이 고정된 상태를 확인했다. 기록: `output/floor-plan-panel-resize/before.png`.
- 변경 후 `npm.cmd test` 전체 통과. 호환 페이지 동기화와 JS 구문 검사 통과.
- Viewer와 Editor 각각 포인터로 왼쪽 +150px, 오른쪽 +160px 확대를 확인했다. 패널 내부 항목·입력 값과 도면 위치, 브라우저 초안 문자열이 동일했고 임시저장 버튼도 계속 비활성이었다.
- 좁힌 우측 패널에서 입력란 한 열 정렬, 좌측/우측 최소·최대 폭, 방향키 조절, 더블클릭 기본 폭 복원 확인.
- 브라우저 폭 1050px에서 도면 최소 폭과 패널 가로 넘침 없음, 720px에서 기존 작은 화면 배치와 조절 경계 숨김, 1600px 복귀 후 항목 보존 확인.
- 폭 조절 후 숫자 자동 반영·축 선택·임시저장·실행취소 확인.
- 기존 브라우저 검사 주요 19개, 축 설정 6개, Grid/화면 이동 9개, 랙 12개, 정밀도 7개, Viewer 7개 묶음 모두 통과했다. 최종 실패 항목 없음.

검증은 독립 Edge headless 프로필에서 마우스 드래그·클릭·키보드로 수행했다. 사용자 Chrome 프로필 및 모바일 터치 조작은 검사하지 않았다. 사용자 저장 데이터, 원본 Google 시트, 실제 배포 사이트는 변경하지 않았다. 결과와 화면: `output/floor-plan-panel-resize/`.
