# 랙 패널 입력 영역 정리

2026-09-18 요청한 우측 패널 변경:

1. 랙 제목을 `랙 기준 정보`로 변경.
2. 랙의 `속성 변경은 자동 반영됩니다` 안내 영역 삭제. 실제 자동 반영과 입력 오류 안내는 유지.
3. `배치 가로`, `배치 세로`를 기존 랙 규격 입력 영역 마지막으로 이동.
4. `베이 사이 간격`, `랙열 사이 간격`을 배치 크기 입력 다음으로 이동.
5. 기준점 선택 영역 제목을 `위치 및 방향 설정`으로 변경. X·Y와 회전 버튼은 이 영역 아래에 유지.

입력 필드의 이름과 기존 이벤트·계산·저장 형식은 유지했습니다. 랙타입을 지정하지 않아도 크기·간격 필드는 표시합니다. 패널 폭에 따라 기존 자동 레이아웃으로 정렬합니다.

## 수정 파일

- `js/floor-plan-editor.js`: 랙 제목·안내 영역·입력 필드 구성, 위치 영역 제목.
- `index.html` 및 동기화한 12개 호환 진입 페이지: 에디터 캐시 버전 변경.
- `tests/floor-plan-rack-layout-browser.cjs`: 변경 전 재현 및 변경 후 브라우저 검증.

## 검증 결과

변경 전 `npm.cmd test` 전체 통과. Edge에서 기존 제목, 안내 문구, 배치 크기·간격이 위치 영역 아래에 있는 상태 재현.

변경 후 `npm.cmd test` 전체 통과.

격리된 Edge Viewer·Editor에서 확인:

- 요청한 두 제목 표시, 랙 안내 영역 없음.
- 크기·간격 네 입력 필드가 규격 영역에 한 번씩 표시되고 위치 영역보다 위에 배치됨.
- 최초 표시만으로 저장 내용이나 변경 상태가 바뀌지 않음.
- 가로 9.50 m, 세로 3.50 m, 베이 간격 0.10 m, 열 간격 0.20 m, X 10.00 m, Y 11.00 m 입력 후 Enter·임시저장 → 저장값 일치.
- 시계 방향 회전과 되돌리기 정상.
- 가로 0 입력 → 오류 안내 유지, Esc → 9.50 m 복원.
- 잠금 시 이동한 네 입력 필드도 비활성화.
- 다른 대상의 기존 제목·입력·안내 유지.
- 랙타입 미지정 및 새 랙 배치에서 크기·간격 필드 유지.
- 최대·최소 패널 폭에서 자동 정렬, 가로 넘침 없음.

기존 랙 브라우저 회귀 12개, 기준점·드래그 Grid snap 6개 항목 통과. 기존 에디터 브라우저 회귀는 최초 실행에서 19개 기능 항목 통과 후 외부 Mermaid 스크립트의 `mermaid is not defined` 오류로 실패했고, 동일 절차 재실행에서 오류 없이 통과했습니다. 공통 스크립트는 수정하지 않았습니다.

현재 사용자 Chrome 탭·모바일 기기에서는 직접 확인하지 않았습니다. 기존 도면이나 원본 Google 시트에는 쓰기를 실행하지 않았습니다.
