# 랙 속성 저장 결과 팝업

2026-09-18: 선택한 랙의 `속성 저장` 입력창에서 저장 실행 후 결과 팝업을 추가했습니다.

- 성공: `저장을 성공했습니다. [기준정보 새로 불러오기] 버튼을 클릭해 업데이트 해주세요.`
- 실패: `저장에 실패했습니다.`

팝업은 브라우저 중앙에 표시하고 `확인`으로 닫습니다. 성공 팝업은 기존 저장 모듈이 원본 시트 응답과 추가 행을 확인한 뒤 표시합니다. 실패 팝업을 닫으면 코드·이름 입력창과 상세 오류를 유지합니다. 원본 반영 여부를 확인하지 못한 경우에는 실패 안내를 표시하면서 기존의 재시도 차단을 유지합니다. 입력 형식 오류는 저장 전 검증 단계이므로 기존 입력창 안에서 안내합니다.

## 변경 파일

- `js/floor-plan-editor.js`: 결과 팝업, 랙 저장에만 사용하는 성공·실패 안내 처리, 메뉴 이동 시 열린 팝업 정리.
- `index.html`과 동기화한 12개 호환 진입 페이지: 캐시 버전 갱신.
- `tests/floor-plan-save-result-browser.cjs`: 변경 전 재현 및 성공·실패 결과 검증.
- `tests/floor-plan-rack-save-browser.cjs`: 결과 팝업 확인 후 기존 검증을 이어가도록 조작 순서 변경.

Google 저장 모듈, 인증·권한, 마스터 열 구성, 이름·코드 중복 방지, 도면 저장 형식은 변경하지 않았습니다.

## 검증 결과

변경 전 `npm.cmd test` 전체 통과. 기존 저장 모듈에 시험 Google 응답을 제공한 Edge 브라우저에서 성공 후 팝업 없이 입력창이 닫히고 실패가 입력창에만 표시되는 상태 재현.

변경 후 `npm.cmd test` 전체 통과. 격리된 Edge Viewer·Editor에서 동일 절차로 확인:

1. 저장 성공 및 추가 행 재조회 확인 → 성공 팝업과 정확한 문구 표시. 중앙 배치, 확인 후 닫힘.
2. 편집 권한 오류 응답 → 실패 팝업과 정확한 문구 표시. 확인 후 입력 코드·이름·상세 오류 유지.
3. 실패 확인 후 재시도 → 한 번 추가되고 성공 안내.
4. 추가 후 행 확인 실패 → 실패 팝업. 확인 후 저장 재시도 버튼 차단 유지.
5. 결과 팝업이 열린 상태에서 메뉴 이동 → 결과 팝업과 원래 입력창 모두 정리, 복귀 시 남은 팝업 없음.

최초 결과 팝업 검증에서 확인 후 닫기 이벤트까지 DOM 정리가 지연되는 항목이 실패했습니다. 확인 시 즉시 팝업을 정리하도록 보완하고 Viewer·Editor 재검증에서 통과했습니다.

기존 속성 저장 브라우저 검증 통과: 여섯 규격 필드, 다른 랙 보존, 삭제·되돌리기, Google 설정 누락 오류, 코드 형식, 코드 중복 시 추가 금지, 이름 시간 자동 완성, 여덟 열 추가 및 재조회 확인.

기존 에디터 브라우저 검증은 19개 기능 통과 후 외부 Mermaid 스크립트 로드 오류로 한 번 실패했습니다. 같은 검증을 다시 실행해 오류 없이 통과했습니다.

실제 Google 시트에 항목을 추가하지 않았습니다. 저장 성공·실패 및 원본 응답 처리는 실제 제품 코드를 시험 응답과 연결해 검증했으며, 현재 브라우저의 Google OAuth 설정 누락 실패도 확인했습니다. 사용자 Chrome 탭·모바일 기기에서는 직접 검증하지 않았습니다.
