# 축 설정 패널 이동 및 반복 복제 제거 (2026-09-17)

축 설정을 좌측 배치 도구 아래에서 우측 속성 패널로 옮겼다. 랙은 한 베이 가로/전체 깊이/높이/단수/깊이 방향 셀 수/단당 높이 입력 뒤, X/Y 입력 앞에 표시한다. 버퍼·도크·스테이션은 대상별 코드와 치수·방향 입력 뒤, 외곽 왼쪽 위 X/Y 입력 앞에 표시한다. 별도의 위치 기준 드롭다운은 표시하지 않는다. 새 대상 배치에서는 위치 입력이 없는 경우에도 치수·방향 뒤에 표시한다.

사각형 포인트 선택 UI를 우측 폭에 맞게 작은 정사각형과 설명을 나란히 표시하도록 구성했다. 다섯 기준점의 Grid snap, 대상별 축 저장, 이동 드래그 중에만 축 강조하는 동작은 유지한다. 선택 대상이 없거나 경로 도구이면 숨기며, 다른 대상으로 전환하거나 임시저장/재진입해도 같은 동작을 유지한다.

반복 복제 접기 영역, 개수/간격/방향 입력, 복제 배치 버튼과 해당 실행 코드를 제거했다. 기존에 복제로 생성한 도면 대상은 삭제하지 않는다. 도면 저장 형식/키 및 축 계산은 변경하지 않았다.

수정 파일:

- `js/floor-plan-editor.js`: 축 컨트롤 이동 및 기존 컨트롤 재사용, 반복 복제 UI/실행 제거, 빈 선택 처리
- `css/floor-plan-editor.css`: 우측 패널의 작은 사각형/설명 배치
- `index.html` 및 동일한 호환 진입 페이지 12개: 캐시 버전 갱신 및 동기화
- `tests/floor-plan-axis-browser.cjs`: 우측 위치/규격과 좌표 사이 순서/좌측 및 반복 UI 제거 확인. 정렬 검증 후 대상이 겹치지 않게 이동해 실제 대상 드래그 검증 유지
- `tests/floor-plan-precision-browser.cjs`: 제거한 복제 간격 대신 복제 UI 부재 검증
- 이 문서와 기존 평면도 사용/축 설정 문서: 현재 배치 기록

검증:

- 변경 전후 `npm.cmd test` 전체 통과
- 변경 전 Edge에서 축 UI가 좌측에 있고 반복 복제가 표시되는 상태 재현
- 변경 후 Edge Viewer/Editor에서 우측 축 설정의 DOM 배치 순서, 좌측 제거, 반복 복제 제거, 다섯 대상과 선택점의 이동/스냅, 잠금/회전/정렬 안내/임시저장/실행 취소/다시 실행/새로고침/새 배치 확인
- 기본 편집 브라우저 19개, 정밀도 브라우저 7개 묶음 통과
- 기본 브라우저 검사 최초 실행에서 기존 외부 Mermaid 스크립트가 로딩되지 않아 `mermaid is not defined` 오류가 발생했다. 기능 조작 검사는 모두 통과했고, 같은 검사를 재실행해 오류 없이 통과했다. 공통 Mermaid 코드는 변경하지 않았다.
