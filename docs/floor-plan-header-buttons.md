# 평면도 에디터 상단바 버튼

2026-09-18 요청 범위: 기준정보 새로 불러오기와 전체 화면 버튼 추가.

## 사용 방법

- **기준정보 새로 불러오기**: 연결된 공개 Google 시트의 `랙타입 마스터`를 읽어 드롭다운의 기준정보 목록을 갱신합니다. 현재 에디터가 사용하는 기준정보는 랙타입입니다. 도면에 배치한 랙, 선택한 규격, 입력 중인 속성, 임시저장 내용은 덮어쓰지 않습니다. 새 규격을 사용하려면 갱신된 목록에서 타입을 선택합니다.
- **전체 화면**: 에디터 영역을 브라우저 전체 화면으로 확대합니다. 버튼이 `전체 화면 종료`로 바뀌며 다시 누르면 해제됩니다. 에디터 메뉴를 떠날 때도 전체 화면을 해제합니다.

공개 시트 읽기는 3D 화면과 같은 Google Visualization 조회 방식을 사용합니다. 읽기에는 Google OAuth 설정이 필요하지 않습니다. 기존 `속성 저장`의 원본 시트 쓰기 설정과 동작은 변경하지 않았습니다.

## 변경 파일

- `js/floor-plan-editor.js`: 상단바 버튼, 목록 갱신, 전체 화면 상태·이벤트 정리.
- `js/floor-plan-rack-master.js`: 공개 마스터 조회, 열 구성·고유 코드·수치 검증, 실패·시간 초과·취소 처리.
- `css/floor-plan-editor.css`: 전체 화면 크기.
- `index.html` 및 `npm.cmd run sync:pages`로 동기화한 12개 호환 진입 페이지: 관련 파일 캐시 버전 갱신.
- `tests/floor-plan-header-browser.cjs`, `tests/floor-plan-master-read.test.cjs`: 해당 기능 검증.

## 검증

변경 전 `npm.cmd test` 전체 통과. 변경 전 Edge 브라우저에서 두 버튼이 없는 상태 확인.

변경 후 `npm.cmd test` 전체 통과. 공개 마스터 읽기 검사 통과: 정상 행, 빈 행, 코드 중복, 누락·잘못된 수치, 열 구성 변경.

격리된 Edge 브라우저의 Viewer와 Editor에서 확인:

1. 랙 가로 크기를 8.50 m로 입력 후 Enter → 갱신 버튼 클릭 → 새 기준정보 항목 표시. 수정된 크기, 임시저장 전 변경 상태, 기존 브라우저 저장 내용 유지.
2. 시트 오류 응답 → 실패 안내 표시, 마지막 정상 목록 유지, 재시도 가능.
3. 전체 화면 클릭 → 에디터 확대·종료 버튼 표시 → 다시 클릭 → 해제. 편집된 크기 유지.
4. 새로 불러온 랙타입 선택 → 임시저장 → 초안에 선택한 타입 반영.
5. 전체 화면에서 메뉴 해시를 변경 → 확대 해제 → 에디터 복귀 → 도면 유지.

실제 공개 Google 시트 조회 성공: 랙타입 5개. 원본 시트에는 쓰기를 실행하지 않았습니다.

기존 `tests/floor-plan-browser.cjs`의 19개 항목 통과: 자동 속성 반영, 입력 오류 복원, 되돌리기, 경로 핸들·대각선, 터널 정렬, 랙 크기·회전·잠금, 내보내기, 닫기 경고, 초안 복원, 메뉴 복귀, 팝업 정렬.

전체 화면 상태가 바뀐 직후 버튼 상태를 검사하던 최초 검증에서는 이벤트 처리 시점 차이로 실패했습니다. 브라우저의 `fullscreenchange` 반영까지 기다리도록 검증을 보완했으며 Viewer·Editor 재실행에서 통과했습니다.

사용자의 현재 Chrome 탭과 모바일 기기에서는 직접 확인하지 않았습니다. 기준정보 조회는 공개 공유 상태와 네트워크 연결에 따라 실패할 수 있으며, 실패 시 기존 목록과 도면을 유지합니다.
