# 도면 파일 저장·열기

## 사용 방법

- **저장**: 현재 선택한 도면 탭 하나를 `도면 이름.gics`로 저장한다. 다른 탭의 도면이나 실행 취소 기록은 파일에 포함하지 않는다. 해당 도면의 크기, Grid 간격, 배치 대상, 위치·방향, 랙 속성과 축 설정을 포함한다.
- 저장 위치 선택을 지원하는 브라우저에서는 처음 저장할 때 위치와 파일명을 선택한다. 같은 열린 탭에서 다시 저장하면 선택한 파일에 기록한다. 파일 연결은 에디터를 다시 열거나 새로고침하면 유지되지 않는다.
- 저장 위치 선택을 지원하지 않는 브라우저에서는 `.gics` 파일 다운로드를 시작한다. 저장 위치는 브라우저 다운로드 설정을 따른다.
- **열기**: `.gics` 파일을 선택하면 가장 마지막 순서에 새 탭으로 추가하고 그 탭을 선택한다. 현재 탭과 다른 탭은 덮어쓰지 않는다. 같은 파일이나 같은 도면 이름도 별도 탭으로 열 수 있다.
- 기존 에디터의 v1/v2 JSON 파일도 새 탭으로 열 수 있다.
- 변경 표시는 탭별로 관리한다. 한 탭을 저장해도 다른 탭의 미저장 변경은 남는다. 현재 탭에서 작성 중인 경로는 완성하거나 취소한 뒤 저장한다. 다른 탭에서 작성 중인 경로는 현재 탭 저장을 막지 않는다.
- 저장 취소·실패 시 도면은 유지하며 미저장 표시를 해제하지 않는다. 파일 저장 중 추가로 편집한 내용은 저장한 시점 이후의 변경으로 남는다.
- 최대 2MB의 올바른 도면 파일만 연다. 도면 탭은 최대 50개다. 잘못된 파일이나 지원하지 않는 파일 버전은 기존 탭을 변경하지 않는다.

## 이전 브라우저 초안과의 관계

기존 브라우저 초안과 탭 목록은 계속 읽을 수 있고 원본 저장 키를 삭제하거나 덮어쓰지 않는다. 이제 [저장]은 전체 탭을 브라우저에 저장하는 기능을 수행하지 않는다. 필요한 각 탭을 `.gics` 파일로 저장한 뒤, 다음 실행에서 [열기]로 연다. 이전 브라우저 초안이 있으면 새로고침 시 이전 초안이 다시 나타날 수 있다.

저장하지 않은 변경이나 작성 중인 경로가 있으면 브라우저를 닫거나 새로고침할 때 기본 종료 경고를 제공한다. 종료를 취소한 후 필요한 각 도면을 저장한다. 브라우저 경고창 자체에서 파일을 저장하지는 않는다.

## 파일 구조

`.gics` 파일의 내용은 UTF-8 JSON이며 `format: gics-floor-plan`, `version: 1`, `plan`으로 구성한다. `plan`은 기존 `plandy-floor-editor` v2 도면 구조를 사용한다. 이 외부 파일 형식 버전과 내부 도면 버전은 별개이며, 잘못된 형식·버전·중복 코드 등을 검증한 후 탭을 추가한다.

## 검증 결과

- 변경 전 `npm.cmd test` 통과. Viewer·Editor에서 `floor-plan.json` 다운로드와 현재 탭 교체 확인창을 실제 Edge 브라우저에서 재현했다.
- 변경 후 `npm.cmd test` 통과. `.gics` 형식 왕복, 기존 v1/v2 JSON 호환, 버전·중복 코드 검사, 파일명 검사 포함.
- `tests/floor-plan-gics-browser.cjs`: Viewer·Editor에서 실제 `.gics` 다운로드 → 파일 선택 → 마지막 탭 추가 → 다시 저장을 확인했다. 단일 탭 내용, 기존 탭의 배치와 실행 취소 기록, 탭별 변경 표시, 잘못된/너무 큰 파일의 보존, 기존 브라우저 저장 데이터 유지, 작성 중인 경로, 실제 종료 경고, 모든 탭을 닫은 뒤 파일 열기를 확인했다.
- 저장 위치 API의 취소·기록·같은 파일 재사용·실패·비동기 저장 중 추가 편집/탭 전환은 모의 파일 핸들로 확인했다. 운영체제의 실제 저장 위치 선택창과 실제 파일 덮어쓰기는 이 환경에서 직접 검증하지 못했다. 파일 다운로드와 다시 열기는 실제 브라우저 동작으로 확인했다.
- 스크린샷: `output/floor-plan-gics/viewer.png`, `output/floor-plan-gics/editor.png`.
- 이번 변경 파일: `js/floor-plan-editor.js`, `js/floor-plan-model.js`, `index.html`과 동기화된 호환 진입 페이지 12개, `package.json`, 새 파일 형식 테스트·브라우저 테스트 및 이 문서. CSS와 다른 메뉴의 저장·권한 기능은 수정하지 않았다.
