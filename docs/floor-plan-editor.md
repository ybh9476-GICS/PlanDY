# 평면도 에디터

`평면도 에디터` 메뉴의 독립 편집 기능이다. 기준정보 랙타입 마스터의 읽기 전용 사본을 프리셋으로 제공한다. 실행 중 시트를 조회하거나 원본 시트·실제 사이트·3D 화면에 반영하지 않는다. 기존 메뉴·카드 저장 데이터는 사용하거나 수정하지 않는다.

## 기본 사용

1. 로그인 후 Viewer 또는 Editor 권한으로 메뉴를 연다. 왼쪽은 배치 도구와 대상 목록, 중앙은 도면, 오른쪽은 새 배치 또는 선택 대상의 속성이다.
2. 오른쪽 치수 입력은 미리보기 후 **입력창을 벗어나거나 Enter를 누르면 자동 반영**된다. 선택창이나 개별 적용·취소 버튼은 없다. 잘못된 값은 오류와 함께 남기고 Esc로 입력 전 값으로 되돌린다. 반영한 변경은 실행 취소로 되돌린다. 다른 메뉴를 다녀와도 도면 편집 상태를 유지한다.
3. 위치·치수는 m 단위, 소수점 둘째 자리 고정으로 표시한다. 입력을 마치면 0.01m 단위로 반올림하며 개수·단수는 정수다. 기존 도면의 수정하지 않은 값과 회전 계산용 내부 정밀도는 보존한다. 숫자 입력에는 이동 맞춤을 강제하지 않는다. 랙·버퍼·도크·스테이션의 X/Y는 회전 후 외곽의 왼쪽 위로 고정하고, 스캔 터널은 외곽 중심을 사용한다. 별도의 위치 기준 드롭다운은 표시하지 않는다. 방향은 도 단위이며 화면의 Y축이 아래로 향하므로 양수 방향은 시계 방향이다.
4. 도형은 드래그로 이동하고 네 모서리로 크기를 조정한다. 회전은 실제 가로·세로 치수를 유지한다. 대상 코드 옆 잠금 버튼으로 위치·크기·삭제를 잠글 수 있다.
5. 한 번 배치한 뒤에는 선택 모드가 된다. 여러 개를 연속해서 놓으려면 `연속 배치`를 켠다.
6. 실행 취소는 Ctrl+Z, 다시 실행은 Ctrl+Shift+Z / Ctrl+Y다. 입력창에서는 기본 텍스트 편집 단축키가 유지된다. 방향키는 선택한 맞춤 간격만큼 이동하며 Shift는 10배다.
7. 휠/+/-로 확대하고 **빈 바닥을 드래그**해서 도면을 이동한다. 대상 드래그는 해당 대상의 위치를 바꾼다. 선택·화면 이동 전환 버튼은 없다. `전체 맞춤`과 `선택 맞춤`을 구분한다.

## 경로와 핸들

- AMR·셔틀 통로와 컨베이어는 클릭마다 지점을 추가한다. 지점이 하나면 Esc로 취소하고, 두 개 이상이면 Esc로 완성한다. `직각 제한`을 끄면 대각선으로 이어진다. 분기 지점에서도 다시 분기할 수 있으며 번호는 `2-1`, `2-2-1`처럼 상위 지점 번호를 이어받는다.
- 완성한 경로의 원형 핸들을 선택해서 끌거나, 오른쪽 지점 번호를 눌러 X/Y를 입력한다. `경로 전체`를 선택하면 시작점 X/Y 변경으로 전체 경로를 이동한다.
- 구간을 선택해 길이·방향을 입력할 수 있다. 구간 끝과 이후 지점들을 함께 이동하여 뒤쪽 구간 모양을 유지한다.
- 선을 더블클릭하면 해당 구간에 지점을 추가한다. `구간 중간에 지점 추가`도 지원한다. 선택한 지점은 삭제할 수 있지만 최소 두 지점은 남긴다.
- 폭은 중심선에 수직인 두께다. 폭을 바꿔도 지점 좌표와 중심선 길이는 변하지 않는다. 그리기를 취소하면 기존 객체는 보존된다.
- `Grid`는 선 표시를 켜고 끈다. `Grid snap`은 이동·배치·크기 조절을 Grid 간격에 맞춘다. 상단 간격(0.01/0.1/0.5/1/2m)과 도면 설정의 Grid 간격은 동일한 값이며 저장·실행 취소·불러오기에 함께 반영된다. 도면 설정에서 입력한 사용자 간격도 상단에 표시한다. 기존 대상의 치수는 간격을 바꿔도 그대로다.
- 작은 간격은 축소 상태에서 선을 구분하기 어려워 확대 안내가 표시된다. Grid를 숨기지 않으며 충분히 확대하면 세부 선을 확인할 수 있다.
- `정렬 안내`는 다른 대상의 외곽·중심과 가까우면 주황색 선을 보여준다. Grid snap이 켜져 있으면 정렬 위치에도 맞추며, 끄면 선만 보여준다. 옆의 `?`에서 설명을 볼 수 있다. 직각 제한은 별도다.
- 배치 도구 사용 중에도 바닥 드래그는 화면만 이동한다. 클릭으로만 대상/경로 지점을 추가한다. 4px 이상의 드래그를 클릭과 구분하며 화면 이동은 변경 사항이나 실행 취소 기록에 포함하지 않는다.

## 에디터 전용 랙타입 마스터

상단 `랙타입 마스터`에서 타입 코드·명칭·한 베이 가로·한 랙열 전체 깊이·높이·단수·깊이 방향 셀 수를 등록하거나 수정한다. 프리셋은 2026-09-17 기준정보의 `랙타입 마스터` A4:H를 읽어 확인한 5개 타입이다. 코드·이름·가로·깊이·높이·단수·단당 높이·깊이 수를 원본 그대로 보존한다. 예를 들어 PALLET-4L은 이름에 4단이 있지만 원본 단수 값은 10이므로 계산에는 10을 사용한다. 출처와 값은 `data/floor-plan-rack-presets.json`에 기록했다. 자동 동기화하지 않는다.

랙 속성창 위쪽은 대상 코드·잠금·변경 버튼, 랙타입 드롭다운, 셀 수 순서다. `변경`은 선택한 랙의 타입 속성만 팝업에서 편집하며 다른 랙은 유지한다. 프리셋과 기존 도면의 사용자 타입을 구분해 선택한다. 기존 도면의 타입 정의를 프리셋으로 덮어쓰지 않는다. 방향은 시계/반시계 90° 버튼으로 바꾸며 외곽 왼쪽 위 X/Y와 실제 가로·세로 치수를 유지한다. 잠금 시 이동·치수·타입·속성 변경·삭제를 막는다. 삭제 버튼은 속성 영역 전체 폭을 사용한다.

- 가로 베이 수 = `floor((배치 가로 + 베이 간격) / (베이 가로 + 베이 간격))`
- 랙열 수 = `floor((배치 세로 + 랙열 간격) / (한 열 깊이 + 랙열 간격))`
- 바닥 셀 수 = `베이 수 × 랙열 수 × 깊이 방향 셀 수`
- 전체 셀 수 = `바닥 셀 수 × 단수`

셀 수는 속성창 상단에 고정 표시한다. 실제 점유 치수·남는 공간·타입 규격은 상세에 표시한다. 예를 들어 1.23m 베이, 1.23m 깊이, 깊이 2셀, 4단 타입에 2.46 × 1.23m를 할당하면 2베이 × 1열, 바닥 4셀, 전체 16셀이다. 베이·열 간격을 추가하면 수가 다시 계산된다.

도면의 셀 그림은 실제 점유 영역 안에 그린다. 성능을 위해 한 객체당 그림은 최대 800셀까지 표시하며, 계산된 숫자는 전체 셀 수다. 마스터를 수정하면 같은 타입을 사용하는 객체들의 계산도 함께 갱신되고 실행 취소로 되돌릴 수 있다. 이 계산은 수납 셀 개수이며 적재 중량·기둥 두께·안전 여유·물류 운영 가능성을 판정하지 않는다.

## 스캔 터널

진행 방향의 길이와 통과 폭을 구분한다. 스캔 터널의 X·Y는 항상 회전 후 외곽의 중심 좌표로 표시하며 별도의 위치 기준은 선택하지 않는다. 에디터 안의 컨베이어를 선택하고 시작점부터 중심선 거리(m)를 입력한 뒤 `컨베이어에 위치·방향 맞춤`을 누르면 해당 위치와 진행 방향에 맞춘다. 컨베이어 폭보다 터널 폭이 좁거나, 위치·방향이 어긋나거나, 터널 길이가 끝을 넘으면 안내한다. 컨베이어를 나중에 바꿔도 터널을 몰래 이동하지 않으며, 경고를 보고 다시 맞출 수 있다.

도면의 사각 배치 대상(W, BT, B, D, S)은 외곽 왼쪽 위에 `코드 : 가로 길이 m x 세로 길이 m , 각도°`를 표시한다. 트랙(T, ST, CV)은 같은 위치에 `코드 : 폭 m , 총 길이 m`를 표시한다. 랙의 가로·세로 길이는 요약 바로 아래에 배치하고, 트랙의 중심선 총 길이는 경로 편집 버튼 바로 위에 배치한다.

버퍼·도크·스테이션의 우측 패널은 각각 `버퍼 정보`, `도크 정보`, `스테이션 정보`로 표시한다. 코드 입력은 `버퍼 코드`, `도크 코드`, `스테이션 코드`로 구분하고 잠금 버튼을 코드 옆에 둔다. 치수·방향, 축 설정, 외곽 왼쪽 위 X/Y, 회전, 삭제 순서로 표시하며 위치 기준 드롭다운과 하단 체크박스 잠금은 사용하지 않는다.

분기는 별도의 전체 삭제 버튼을 사용하지 않는다. 분기 포인트도 `포인트 삭제`로 하나씩 제거하며, 마지막 고유 포인트를 삭제하면 해당 분기와 연결된 하위 분기를 함께 정리한다. 다른 분기의 시작점인 포인트를 삭제하는 경우에도 그 포인트에서 시작된 하위 분기를 함께 정리한다.

## 저장·호환성

> 현재 파일 저장·열기 동작은 [도면 파일 저장·열기](floor-plan-gics-files.md)를 따른다. 아래 임시저장·JSON 내보내기 관련 설명은 이전 기능의 기록이다. [저장]은 선택한 탭 하나를 `.gics`로 저장하고 [열기]는 마지막 순서에 탭을 추가한다.


- 저장 키: `wms-floor-plan-editor-draft-v2:<menuId>`; JSON: `format: plandy-floor-editor`, `version: 2`.
- 이전 v1 초안과 JSON을 읽을 수 있다. v1 키는 수정·삭제하지 않으며 처음 임시저장할 때 별도 v2 키에 저장한다. 이전 경로의 차지하던 영역과 사각형 치수를 보존한다. 랙타입을 모르는 예전 랙은 타입 미지정으로 남기고 직접 지정하도록 안내한다.
- 예전 경로는 외곽을 보존하는 끝단 모양을 유지한다. 새 경로는 중심선 끝에서 끝나는 모양을 사용한다.
- 랙타입 정의는 도면 JSON에 포함된다. 에디터 내보내기를 사용해야 다른 브라우저/PC로 이동할 수 있다. 사이트 콘텐츠 JSON이나 프로젝트 자동 저장에는 에디터 초안이 포함되지 않는다.
- 도면 편집과 브라우저 저장은 분리한다. **내보내기 앞의 임시저장**은 변경 사항이 있을 때만 활성화되고, 눌렀을 때 현재 도면을 저장한다. 저장하거나 실행 취소로 마지막 저장 상태로 돌아가면 비활성화된다. 내보내기는 현재 도면을 파일로 받을 뿐 임시저장을 대신하지 않는다. 실행 취소 기록(최근 80회)은 새로고침 후 남지 않는다. 브라우저 데이터를 삭제하면 초안도 삭제된다.
- 저장하지 않은 변경이나 작성 중인 경로·입력이 있으면 탭 닫기·새로고침 때 브라우저 기본 종료 경고가 표시된다. 브라우저 보안 제한으로 이 경고의 문구·버튼을 사이트가 바꿀 수 없으며, 경고창에서 직접 저장도 할 수 없다. **종료를 취소하고 임시저장 후 다시 닫는다.** 강제 종료·기기 전원 종료까지 보장하는 자동 저장 기능은 아니다.
- 에디터 팝업은 브라우저 콘텐츠 영역 가운데 표시하며 높이가 부족하면 팝업 내부를 스크롤한다.
- 최대 도면 200 × 200m, 대상 500개, 경로당 100지점, 랙타입 50개다. 부적합 입력·중복 코드·경계 이탈은 저장하지 않고 입력과 오류를 남긴다. 겹침은 경고와 함께 초안 저장을 허용한다.
- 다른 탭의 초안 변경이나 저장 실패를 감지하면 편집을 멈춘다. 현재 도면을 내보낸 후 새로고침한다. 손상된 저장 원본은 덮어쓰지 않는다.
- Viewer와 Editor 모두 독립 평면도의 배치·속성 편집·이동·회전·삭제·임시저장·JSON 불러오기/내보내기를 사용할 수 있다. 다른 메뉴의 사이트 콘텐츠 편집은 Editor에게만 허용한다. 로그인 전에는 평면도 편집을 실행할 수 없다.
