# 평면도 축 설정 (2026-09-17)

## 사용 방법

랙, 스캔 터널, 버퍼, 도크, 스테이션을 선택하거나 해당 배치 도구를 선택하면 좌측 패널에 `축 설정`을 표시한다. 사각형의 왼쪽 위·오른쪽 위·중심·왼쪽 아래·오른쪽 아래 버튼 중 하나를 선택한다. 선택한 점은 파란색으로 표시하고 아래에 종류와 위치를 안내한다.

`Grid snap`이 켜져 있을 때, 선택한 점을 Grid 교차점에 맞춰 새로 배치하거나 드래그 이동한다. 새 배치는 클릭한 좌표가 선택한 점의 위치가 된다. 회전한 대상은 기존 위치 기준과 일치하도록 **회전 후 외곽 사각형**의 네 모서리와 중심을 사용한다. 우측 X/Y에는 현재 선택한 점의 좌표를 즉시 표시하며, 값을 입력하면 그 선택점이 입력 좌표로 이동한다. 이 좌표 연동은 랙(W), 스캔 터널(BT), 버퍼(B), 도크(D), 스테이션(S)에 동일하게 적용한다.

도면에서는 이동 드래그 중에만 선택한 축을 주황색 원/십자 표시로 강조한다. 단순 선택·클릭·배치 미리보기·크기 조절·바닥 화면 이동 중에는 축 강조가 없다. 드래그가 끝나거나 취소되면 사라진다. 기존 선택 테두리와 크기 조절 핸들은 유지하며, 대상 이동 중 포인터도 기존 화살표를 유지한다.

- 기본값: 왼쪽 위
- 대상별로 선택한 축을 임시저장/JSON 내보내기에 함께 보존한다. 설정 변경은 실행 취소/다시 실행으로 복원할 수 있다.
- 아직 배치하지 않은 대상의 축은 배치할 때 해당 대상에 저장한다. 새로운 배치 도구 선택은 기본 축으로 시작한다.
- 잠긴 대상은 축 설정을 바꿀 수 없다.
- Grid snap을 끄면 자유롭게 이동할 수 있다. 이동 중 축 표시는 유지한다.
- 정렬 안내가 선택 축을 Grid 밖으로 이동시키는 경우에는 그 위치로 끌어 맞추지 않는다. 선택 축이 Grid에 유지되는 정렬만 적용한다.
- AMR 통로·가이드 레일·컨베이어에는 축 설정을 표시하지 않는다. 경로 시작점/지점의 기존 스냅은 유지한다.
- 스캔 터널의 명시적인 컨베이어 설치 맞춤은 기존 방식으로 유지한다. 새 배치에서 연결 컨베이어를 지정한 경우 기존 설치 위치/방향 맞춤이 우선한다.
- 축 선택만 바꾸면 대상의 위치·크기·각도는 변하지 않고 X/Y 표시 기준만 선택점으로 바뀐다.

## 수정 파일 및 호환성

- `js/floor-plan-model.js`: 다섯 점 좌표/이동 함수, 직사각형 대상의 선택적 `snapAnchor` 보존 및 값 검사
- `js/floor-plan-editor.js`: 좌측 UI, 대상별 축 변경, 배치 미리보기/클릭/이동에 선택 축 적용, 이동 중 강조, 정렬 안내의 Grid 우선 처리
- `css/floor-plan-editor.css`: 사각형 포인트 버튼 및 선택 상태
- `index.html` 및 같은 호환 진입 페이지 12개: JS/CSS 캐시 갱신, `sync:pages` 동기화
- `tests/floor-plan-model.test.js`, 신규 `tests/floor-plan-axis-browser.cjs`: 좌표·저장 호환 및 실제 조작 검증
- 이 문서와 `docs/floor-plan-editor.md`: 변경 기록

기존 형식 버전2와 저장 키를 유지한다. 이전 도면에는 새로운 축 속성을 강제로 넣지 않으며, 불러오기만으로 좌표/크기/저장 데이터가 바뀌지 않는다. 기본 축이 있는 기존 대상은 그대로 사용할 수 있다. 원본 기준정보나 외부 Google 시트에는 축 설정을 쓰지 않는다.

## 검증 결과

- 변경 전/후 `npm.cmd test` 전체 통과
- 변경 전 Edge에서 축 선택 UI 부재 및 원본 초안 유지 재현
- Edge 독립 프로필 Viewer/Editor: 5종류 대상에 5개 선택점 적용, 이동 중에만 강조/이동 종료 후 제거, 화살표 포인터, 90도 및 35도 회전, 잠금, Grid snap 끄기, 설정 저장/실행 취소/다시 실행/새로고침, 경로 도구 영향 없음, 중심 기준 새 버퍼 및 회전 터널 배치 통과
- 추가 Viewer 조작: 정렬 안내가 켜져 있고 주변 대상이 Grid 밖 좌표에 있어도 선택 축의 Grid 유지 확인
- 기존 브라우저 회귀: 기본 편집 19개, 화면 이동/Grid 9개, 랙 12개, 미터 표시 7개, Viewer 권한 7개 묶음 통과
- 기존 도면 전체와 새 설정의 읽기/실행 취소 호환 검사 통과

화면/도면 결과: `output/floor-plan-axis/`. 사용자 Chrome 프로필과 모바일 터치는 미검증이다. 검증은 별도 Edge 프로필을 사용했으며 사용자 저장 데이터/실제 기준정보 시트를 수정하지 않았다. 최종 실패 항목 없음.


## 축 설정 우측 이동 및 반복 복제 제거 (2026-09-17)

축 설정을 우측 속성 패널로 이동했다. 랙 규격 입력 아래, X/Y 입력 위에 배치하며 반복 복제 UI/실행 기능을 제거했다. 기존 대상과 축 스냅/저장 동작은 유지한다. 상세 수정 및 검증 기록은 [floor-plan-axis-panel-layout.md](floor-plan-axis-panel-layout.md)를 따른다. 이전 좌측 위치 설명은 당시 동작 기록이다.
