# 랙 요약 정보 단일화

2026-09-18: 우측 패널 하단에 있던 랙 상세 요약을 랙타입 선택 바로 아래로 옮겼습니다. 별도로 표시하던 상단 셀 수 요약은 제거했습니다.

한 카드에 베이·열 수, 바닥·전체 셀 수, 실제 점유 크기, 남는 공간, 베이·열·깊이·높이 규격을 표시합니다. 기존 계산, 입력 필드, 축 설정, 회전, 삭제·속성 저장, 저장 데이터는 변경하지 않았습니다. 경로 길이 정보의 기존 위치도 유지합니다.

## 수정 파일

- `js/floor-plan-editor.js`: 표시 위치 이동 및 중복 갱신 제거.
- `index.html` 및 동기화된 12개 호환 진입 페이지: 에디터 캐시 버전 갱신.
- `tests/floor-plan-browser.cjs`, `tests/floor-plan-rack-browser.cjs`: 동일 수치를 통합된 다중 행 카드에서 검사하도록 표시 형식에 맞춤.
- `tests/floor-plan-summary-browser.cjs`: 변경 전 중복 재현 및 변경 후 위치·갱신 검증.

## 검증 결과

변경 전과 변경 후 `npm.cmd test` 전체 통과.

변경 전 Edge에서 상단 셀 수 요약과 하단 상세 카드가 동시에 표시되는 상태를 재현했습니다.

변경 후 격리된 Edge의 Viewer와 Editor에서 확인:

- 상세 카드가 랙타입 아래, 규격 입력 필드 위에 한 번만 표시됨.
- 처음 열 때 기존 저장 데이터와 변경 없음 상태 유지.
- 가로 9.50 m, 세로 3.50 m, 베이 간격 0.10 m, 열 간격 0.20 m 및 단수 변경 후 계산 결과와 요약 일치.
- 되돌리기, 프리셋 선택, 경로 선택 후 랙 복귀 시 요약 정상 갱신.
- 우측 패널을 최대·최소 폭으로 조절해도 요약에 가로 넘침 없음.

기존 에디터 브라우저 회귀 19개 항목과 랙 브라우저 회귀 12개 항목 모두 통과했습니다. 초기 수정용 스크립트는 문법 오류로 적용 전에 중단됐으며, 수정 후 적용·검증했습니다. 실패한 기능 테스트는 없습니다.

사용자의 현재 Chrome 탭과 모바일 기기에서는 직접 검증하지 않았습니다. 원본 Google 시트에 쓰기는 실행하지 않았습니다.
